# DevCleaner

Portable Windows 11 desktop tool for safe filesystem cleanup and read-only Windows investigation.

Development: F# / .NET 11. Approved product constraints are recorded in [`docs/DevCleaner-v1-requirements-review.md`](docs/DevCleaner-v1-requirements-review.md). **Open [GitHub Issues](https://github.com/masterlifting/devcleaner/issues) for current task scope, sequencing, explicit blockers and acceptance.** There is no independently maintained delivery-plan file.

Implementation follows [AGENTS.md](AGENTS.md) and current GitHub Issues, with a task-scoped approved plan and independent PR review. No automated deletion of quarantined data.
